# Support

## Before opening an issue

1. Update Home Assistant and EnOcean Custom.
2. Restart Home Assistant once.
3. Check the integration diagnostics and logs.
4. Confirm the dongle path, sender ID, EEP/profile and radio range.
5. Search existing issues and discussions.

## Bug reports

Use the [bug report form](https://github.com/szymkiewiczmathieu/ha_enocean_custom/issues/new?template=bug_report.yml).

Include the Home Assistant version, integration version, dongle model, exact device profile, reproduction steps and relevant redacted logs. Never publish tokens, passwords, private URLs or full personal addresses.

## Feature requests

Use the [feature request form](https://github.com/szymkiewiczmathieu/ha_enocean_custom/issues/new?template=feature_request.yml). Explain the device, EEP/profile, expected behavior and any available documentation or captures.
